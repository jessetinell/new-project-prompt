# Contributing

New Project Prompt improves through lessons from real projects: something an agent got wrong, a bill that almost happened, a step that confused someone.

1. **Open an issue** saying what happened and what an agent should do instead. Small fixes can go straight to a pull request.
2. **Generalize it.** No project names, URLs or account details.
3. **Keep it brief.** One rule, in the one file it belongs to. Every line should change what an agent does.

Cost-safety and security rules can be added to or clarified, never weakened.

Working with an agent? Open it in this repo: [`AGENTS.md`](AGENTS.md) has the full rules and how to check a change.
